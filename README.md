# EcoGlow Skincare Website

## Project Overview
EcoGlow Skincare is a responsive multi-page e-commerce and brand website developed as part of WEDE5020. The project highlights natural, locally sourced African botanical skincare products.

## Features
- **Responsive Layout:** Built using modern CSS Grid, Flexbox, and media queries to support desktop, tablet, and mobile viewports.
- **External Stylesheet:** Centralized styling inside `css/style.css`.
- **Interactive Elements:** Includes CSS pseudo-classes (`:hover`, `:focus`, `:active`), dynamic gradients, and animated backgrounds.
